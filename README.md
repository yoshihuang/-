岩心箱校正與裁切程式
可將傾斜照片調整為「正面視角（透視校正）」並「裁切去背」，在工程地質與岩心記錄上非常實用

若沒有PYTHON環境,可直接執行 岩心箱校正與裁切程式.exe後,
在程式執行時，會依序彈出兩次視窗：
第一次： 詢問您「來源照片」放在哪個資料夾。
第二次： 詢問您處理完的影像要「輸出」到哪個資料夾。
然後請用滑鼠依序精準點擊岩心黑色外框的：「左上角」➔「右上角」➔「右下角」➔「左下角」。
點完第4個點後，視窗會關閉，並自動在輸出資料夾內生成如正面裁切.jpg 的完美正面影像！然後會自動換下一張，直到全部完成。
這樣不僅不會破壞原始高解析度畫質，還能完美去除土壤、鞋子背景，將梯形變形的岩心箱完全拉正。

你也可以執行 岩心箱校正與裁切程式.py

執行岩心箱校正與裁切程式.py 所需之相關PYTHON環境設定如下:
步驟 1：下載與安裝 Python 主程式
前往官網下載：
開啟瀏覽器，進入 Python 官方下載頁面：https://www.python.org/downloads/
點擊黃色按鈕 "Download Python 3.x.x" (下載最新版本即可)。
執行安裝檔（⚠️最重要的一步）：
打開下載好的安裝檔，在彈出的第一個視窗中，務必勾選畫面最下方的「Add python.exe to PATH」（將 Python 加入系統環境變數）。
(如果不勾選這個，後續會無法在命令提示字元安裝套件)。
勾選後，點擊上方的 "Install Now"，等待安裝完成並關閉視窗。

步驟 2：開啟「命令提示字元 (CMD)」
在 Windows 系統的下方搜尋列 (放大鏡圖示) 輸入 cmd。
點擊開啟 「命令提示字元」 (一個黑底白字的視窗)。
（可選）在黑畫面中輸入 python --version 並按 Enter，如果有跑出版本號，代表步驟 1 安裝成功。

步驟 3：安裝必備的第三方套件
在剛剛打開的黑畫面 (命令提示字元) 中，直接複製貼上以下這行指令，然後按 Enter 鍵：
DOS
pip install opencv-python numpy
系統會自動連上網下載並安裝這兩個套件，畫面會跑進度條。
opencv-python：用來處理影像的讀取、顯示、透視變換裁切。
numpy：用來處理座標陣列與矩陣數學計算。
(當畫面顯示 Successfully installed... 並回到閃爍游標，就代表安裝完成了)

步驟 4：執行程式
將您的 core_box_cropper.py 放到電腦中的任何資料夾。
對著該檔案點擊右鍵 ➔ 選擇 「Open with (以...開啟)」 ➔ 選擇 Python，即可直接執行。
或者，您也可以像之前的截圖一樣，右鍵選擇 「Edit with IDLE」，然後在上方選單點擊 Run ➔ Run Module (或按 F5) 來執行。
